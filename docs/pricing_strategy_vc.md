# 商业化与定价策略（VC 视角）

## 问题诊断
- **价值表达不清**：用户可感知 AI 拆解价值，但付费理由尚不够“硬”。
- **使用频率偏低**：若用户只在“偶尔思考”场景使用，很难形成稳定付费习惯。
- **高价值客户未锁定**：真正愿意付费的用户是“研究/决策高频人群”，必须精准定位。

## 定价原则
1. **价值锚定在“决策质量提升”而非“节点数量”**。
2. **付费点绑定高频使用场景（研究、分析、战略）**。
3. **逐步引导：从个人 Pro → 团队 Pro → 企业版**。

---

## 定价分层设计

### Free（0）
- 本地持久化
- 基础模型
- 节点数/主题数限制
- 基础导出（JSON）

### Pro（个人版） $15~$30/月
- 高级模型（更快、更深）
- 可执行结论卡片
- 导出为 PDF / Markdown / PPT
- 主题数量与节点上限大幅提升
- 历史回溯与“引用推理链”

### Team（小团队） $49~$99/月
- 共享图谱与协作
- 版本对比 / 回滚
- 团队知识库（跨项目复用）
- 权限控制（只读 / 编辑）

### Enterprise（定制）
- 私有模型接入 / 私有部署
- 合规与审计（SOC2 / GDPR）
- API 访问与深度集成

---

## 核心付费驱动点（Paywall 核心）
1. **高质量模型 + 深度推理（强烈）**
2. **结论输出能力（可执行成果）**
3. **跨主题复用与团队协作**

---

## 商业化验证指标
- 免费 → Pro 转化率 > 3%
- Pro 留存（3 个月）> 60%
- Team 占比 > 15%

---

## 风险与解决方案
- **风险：用户认为免费够用**
  - 对策：将“结论卡片”与“高级模型”作为强付费核心。
- **风险：定价过高导致转化差**
  - 对策：提供 7 天试用 + 引导式成果展示。
- **风险：团队协作价值不足**
  - 对策：用“复用资产”与“版本控制”强化协作价值。
