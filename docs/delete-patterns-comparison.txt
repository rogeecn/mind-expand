║                           RECOMMENDED SOLUTION                               ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  PRIMARY:   Three-Dot Overflow Menu (Pattern B)                              ║
║             • Hover-reveal on desktop                                        ║
║             • Always accessible on mobile (larger touch target)              ║
║             • Menu contains: Rename, Export, [Divider], Delete               ║
║                                                                              ║
║  SECONDARY: Right-Click Context Menu (Pattern D)                             ║
║             • For power users                                                ║
║             • Same menu structure as three-dot                               ║
║                                                                              ║
║  SAFETY:    Confirmation Modal                                               ║
║             • "Delete Topic?" heading                                        ║
║             • Show topic name + node count                                   ║
║             • [Cancel] [Delete Permanently] buttons                          ║
║                                                                              ║
║  FUTURE:    Toast with Undo (Phase 2)                                        ║
║             • Immediate deletion                                             ║
║             • 5-second undo window                                           ║
║             • Matches Linear/Notion pattern                                  ║
║                                                                              ║

┌──────────────────────────────────────────────────────────────────────────────┐
│ VISUAL HIERARCHY (NYT Style)                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. PRIMARY ACTION (Entire item clickable)                                   │
│     └─ Opens/selects the topic                                              │
│                                                                              │
│  2. SECONDARY ACTIONS (Hover-reveal three-dot)                               │
│     ├─ Rename Topic                                                         │
│     └─ Export Backup                                                        │
│                                                                              │
│  3. DESTRUCTIVE ACTION (Nested, red text, separated)                         │
│     └─ Delete                                                               │
│                                                                              │
│  PRINCIPLE: Destructive actions are NEVER prominent                          │
│             Content preservation > easy deletion                             │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ ACCESSIBILITY REQUIREMENTS                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  KEYBOARD:                                                                   │
│    • Tab → Focuses three-dot button                                         │
│    • Enter/Space → Opens menu                                               │
│    • Arrow keys → Navigate menu items                                       │
│    • Enter → Execute action                                                 │
│    • Escape → Close menu                                                    │
│                                                                              │
│  SCREEN READER:                                                              │
│    • "Options for Coffee Origins" (three-dot button)                        │
│    • "Menu opened" announcement                                             │
│    • "Delete Coffee Origins" (delete button)                                │
│    • "Dialog: Delete Topic?" (modal)                                        │
│                                                                              │
│  FOCUS VISIBLE:                                                              │
│    • 2px ring on focus (not just hover)                                     │
│    • Focus returns to trigger after menu closes                             │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
